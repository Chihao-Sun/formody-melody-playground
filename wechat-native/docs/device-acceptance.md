## 玩法

- [ ] 按住才拿起，松手才投出，别处触摸不误投；正常、很慢、很快、转圈、被系统取消的手势均可用。
- [ ] 水漂普通 2–4 次、稀有 6–10 次，高抛一次；原始落点音色和后续弹跳同声部。
- [ ] 同时在途石头保留；四块石头全部落定才成章，每颗石头只计一次。
- [ ] 1/6 稀有规则、五声部补齐不增加重复波源。
- [ ] 轻点／快速点水面增加力度不改变音乐时序；多指保持、逐指松开、取消触摸不遗留按住状态。
- [ ] 约 22 秒结束后保持湖面，不自动重开；第 8 秒寻石渐现、第 9 秒可用，点击后正常重开。
- [ ] 注意：原代码重开旧源的实际退场参数为 3.5 秒；旧 README 的“约九秒”文字与实现不一致，本迁移以源码实际行为为准。
- [ ] 原版数学页面可拖动／点置 Seed、播放／暂停、重置，轨迹高亮跟随声音，返回继续保留湖畔状态。

## 声音、震动、姿态与生命周期

- [ ] 有声／静音进入均可玩，首次确认音和即时落水同步，图标状态正确。
- [ ] 五种合成音色、稀有泛音、循环音高和节拍与网页相同；混响兼容尾音另行试听，标记可接受差异。
- [ ] 静音键、系统音量、蓝牙耳机、插拔耳机、来电／音频打断后可恢复，无爆音、明显削波或一串补播。
- [ ] 真实触水震动：首次较强、逐次减弱；关闭和系统禁止后的降级准确。接口 success 不代替手感确认。
- [ ] 初始姿态校准，左右／前后倾斜方向与幅度正确；拒绝、停用、无数据、横屏反向均不阻挡玩法。
- [ ] 少动态效果开关确实减弱风、飞鸟、石头动画及倾斜；玩法与音乐不丢失。
- [ ] 设置、后台、小程序切换、返回、卸载：不偷偷播放／采集，不丢轮次，不多开计时器／动画循环；返回恢复后可继续投石。
- [ ] 低端机长时间多波源／四声部帧率、内存和耗电可接受，记录测量而非编造数字。
